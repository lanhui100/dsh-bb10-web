# Agent Note: 模型面板增加 D 键设置默认模型确保新建会话不飘移

Status: implemented

## Problem

在 BlackBerry Q20 物理键盘上，用户在按 `M` 打开模型选择面板后，虽然可以通过 `F` 收藏常用模型，但缺乏一个持久化“默认模型”的快捷机制。当用户重新进入页面、刷新 bootstrap 或切换新建会话时，若未持久化保存默认模型偏好，模型选择可能会被远端配置回退或产生飘移。用户需要通过快捷键 `D` 将选中的模型设为全局默认模型，使新创建的会话始终默认采用该模型，避免新建会话模型飘移。

## Decision

1. **默认模型存储与读取契约**：
   - 使用 `localStorage` 键 `dsh_q20_default_model` 持久化保存默认模型值（形如 `provider:::model`）。
   - 提供 `loadDefaultModel()` / `saveDefaultModel(val)` 存取函数，严格包裹异常捕获。
2. **模型面板树状渲染呈现**：
   - 在 `renderModelTree()` 渲染模型条目时，若该条目与当前默认模型匹配，在其标题右侧添加 `[默认]` 标识标签（高亮绿色 `#4EC9B0`，小字号），直观呈现当前设定的默认模型。
   - 更新模型面板底部的提示文案（`.tree-hint`）及快捷键速查面板（`H` / `?`），增加 `D 设为默认模型`。
3. **按键交互与状态流转**：
   - 在模型面板打开态（`isModelOpen`）下，当用户通过 `J` / `K` 光标选中某模型条目时，按物理键 `D`（`code === 68`）：
     - 将当前光标所在模型的 `val` 写入 `localStorage`（键 `dsh_q20_default_model`）；
     - 同步选中该模型（`modelSelect.selectedIndex = targetNode.idx` 并更新徽章 `updateWsBadge()`）；
     - 触发 `renderModelTree()` 重新渲染，保持光标位置稳定并展示 `[默认]` 标识；
     - 底栏状态条给出明确反馈：`已设为默认模型: xxx [D]`。
4. **新建会话防飘移锁定**：
   - 在 `renderBootstrap(data)` 初始化模型选项时：
     - 首先尝试匹配已保存的 `loadDefaultModel()`；
     - 若本地设定了有效默认模型且存在于模型列表中，优先将其选定为当前模型（覆盖后端 fallback 默认值）；
   - 在 `startNewChat()` 执行新建会话逻辑时：
     - 若本地设定了有效默认模型，检查并强制恢复 `modelSelect` 为默认模型，确保新建会话模型绝对不会飘移。
5. **宪法与兼容性约束**：
   - 遵循严格 ES5 规范，无现代语法泄漏；
   - 补充 `test-unit.mjs` 测试覆盖与验证。

## Alternatives considered

- **自动将每次发送对话所用的模型自动记为默认模型**：当用户只是临时尝试某个大模型（例如单次跑重度代码审查）时，会意外破坏日常默认模型偏好；显式通过 `D` 键主动声明更精准、可预期。
- **仅在后端配置中修改默认模型**：多用户或多客户端共享同一后端时会相互干扰；黑莓 Q20 客户端作为独立物理手持端，通过客户端存储独立锁定默认模型最贴合硬件与移动场景。
