# Agent Note: 模型选择面板头部增加常用模型分组与 F 键收藏

Status: implemented

## Problem

在 BlackBerry Q20 的 720×720 方屏上，可用模型列表按 Provider 分组排列（共包含十几个至数十个模型）。当用户频繁在固定的两三个主力模型（如 `gemini-3.8-flash-high`、`claude-3-5-sonnet`、`deepseek-v4-flash`）之间切换时，每次按 `M` 打开面板都需要滚动较长距离查找。用户需要一个常驻面板头部的“常用”模型分组，并支持在通过 JK 键盘光标选中模型时按快捷键 `F` 快速收藏/取消常用。

## Decision

1. 在 `static/index.html` 中维护常用模型列表并持久化至 `localStorage`（键名 `dsh_q20_fav_models`）。
2. 在 `renderModelTree()` 头部优先渲染“⭐ 常用”分组（section 字段与标题为“常用”），展示当前收藏的模型数量及列表。
3. 当用户通过物理键盘 `J` / `K` 光标聚焦到任意模型条目时，按物理键 `F`（`code === 70`）即可切换收藏状态：
   - 若未收藏，则添加到常用模型中并在头部“常用”分组中展示，并在底栏给出即时提示（如 `已添加至常用: xxx`）；
   - 若已收藏，则从常用模型中移除；
   - 保持键盘光标聚焦位置平滑，重新渲染树状节点。
4. 常用分组内的模型条目带有 `★ ` 标识，且点击或按回车均可直接切换生效，并同步关闭面板。
5. 在黑莓 Q20 快捷键速查面板（`H` / `?`）及模型面板底部提示（`.tree-hint`）中注明 `F 收藏/取消常用` 操作。
6. 严格遵循 ES5 语法规范，并通过 `test-unit.mjs` 单测与 `test-suite.mjs` 全链路回归验证。

## Alternatives considered

- **纯硬编码固定默认常用模型**：灵活性差，无法适应不同用户及不同提供商部署的偏好。
- **自动根据使用频次动态排序**：隐式改变列表结构会导致全键盘盲打光标位置突变，打乱肌肉记忆；显式手动按 `F` 收藏由用户完全控制，更稳定可控。
