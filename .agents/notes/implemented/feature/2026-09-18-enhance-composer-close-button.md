# Agent Note: 强化输入框右上角关闭对话框按钮与触控/背景收起闭环

Status: implemented

## Problem
在 BlackBerry Q20 硬件设备上，物理全键盘没有标准 PC 的 `Esc` 键；`Q` 键为 BB10 浏览器保留快捷键；且黑莓物理键盘的 `Alt+字母` 在硬件层面对应键帽上印刻的标点和数字（如 `Alt+I` 硬件产生减号 `-`，`Alt+字母` 会干扰输入文本）。因此，对话框展开后无法通过字母或组合快捷键在打字过程中随意关闭，必须依靠可靠、高触达率的界面触控关闭机制。
此前对话框右上角的「✕」按钮尺寸较小（20×20px），容易误触或难以精准点击。

## Decision
1. **强化对话框右上角「✕」关闭按钮**：
   - 按钮尺寸升级为 26×26px，增大点击靶区；
   - 增加高对比度边框（`1px solid #555555`）与暗色圆角背景（`#333333`），文字设为 14px 粗体白色，触控和视觉均清晰鲜明；
   - 支持 `:active` 高亮按压态（`#555555`），消除点击延迟感；
   - 输入框右侧 padding 拓宽至 46px，确保长文本打字时与右上角关闭按钮及右下角发送按钮保持安全物理间距。
2. **多重触控与键盘闭环交互**：
   - 点击右上角「✕」按钮直接收起对话框并让输入框失焦；
   - 点击对话区域任意空白背景同样自然收起对话框；
   - 按 `Enter` 发送消息后自动收起；
   - 彻底移除对 `Alt+I` 等符号组合键的冲突拦截，确保黑莓用户在输入框内按 `Alt+I` 能够正常键入减号 `-`。
3. **更新帮助与说明文档**：
   - 在快捷键帮助速查表格中明确标注：`✕ 按钮：点击右上角 ✕ 按钮或背景区域收起对话框`；
   - 同步更新中英文 `README.md`。

## Alternatives considered
- **方案 A：使用 `Q` 键收起**：`Q` 是浏览器系统保留键，不可用。
- **方案 B：使用 `Alt+I` 组合键**：在黑莓 Q20 物理键盘上，`Alt+I` 印刻为减号 `-`，拦截该组合键会导致用户打不出减号，引发输入冲突，因此必须放弃。
- **方案 C：使用 `Esc` 键**：黑莓 Q20 物理键盘上没有 `Esc` 键，无法作为实体交互手段。

## Consequences
- 彻底避免了键盘字符输入冲突，保证黑莓 Q20 所有标点符号（包括减号 `-`）打字顺畅；
- 放大并增强了界面关闭按钮，手指触控与光学触摸板点击收起体验大幅提升；
- ES5 门禁 PASS，测试通过。
