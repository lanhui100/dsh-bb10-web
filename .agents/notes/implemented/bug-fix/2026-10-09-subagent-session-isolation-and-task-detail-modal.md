# Agent Note: 严格会话子智能体隔离与团队任务详情弹窗

Status: implemented

## Problem

在当前项目会话中按 `U` 键唤起多智能体面板时，存在两处交互与隔离缺陷：
1. **子智能体加载串台与加载失败**：当前端请求当前会话子智能体（`/api/session/subagents?cwd=...&id=...`）返回为空时，执行了 `loadWorkspaceSubagentsFallback`，回退拉取并展示了全工作区甚至其他会话的子智能体列表，导致用户在当前会话中看到无关子智能体；而在某些会话切换中又出现状态竞争加载失败。
2. **团队任务详情不可点击查看**：多智能体面板顶部的团队任务列表行渲染为 `noop` 静态文本，用户无法通过触控点击或键盘选中回车查看任务的具体要求、描述与验收标准。

## Decision

1. **废弃跨会话回退加载机制**：
   - 彻底移除 `loadWorkspaceSubagentsFallback` 串台拉取全工作区逻辑，保持会话间子智能体的严格隔离性。
   - 当前会话无子智能体或团队任务时，忠实展示会话级空态提示，杜绝其他会话智能体污染。
2. **支持团队任务详情交互查看**：
   - 在面板渲染中将团队任务行标记为 `kind: 'task'` 可交互节点，并接入容器级事件委托与键盘 `J/K + Enter` 响应。
   - 新增符合 BlackBerry Q20 720x720 视口的极简任务详情弹窗（`#task-detail-overlay`），完整展示任务 ID、状态、负责人、版本、依赖前置、写入范围与详细任务描述，支持 `Enter`/`X`/`Esc`/右上角按钮一键关闭。
3. **严格遵守 ES5 语法与抗熵增契约**：
   - 新增逻辑全部通过 Acorn ES5 语法静态门禁，保持原生兼容与老旧 WebKit 高性能。

## Alternatives considered

- 方案 A：在空态时弹窗让用户选择“是否查看工作区全部智能体”。
  - 否决：破坏了 `U` 键“查看当前会话智能体看板”的单一语义，在 720x720 小屏上增加了多余的模态确认阻断，违背沉浸与极简交互原则。
- 方案 B：团队任务点击直接调用 `selectSession` 试图跳转至任务执行者会话。
  - 否决：团队任务并非全部独立绑定到特定的已有子会话，且用户主要诉求是阅读任务验收标准与当前分配状态，详情弹窗更符合直觉。

## Consequences

- 彻底消除多智能体面板串台展示其他会话智能体的 Bug。
- 用户可直接在 Q20 界面上查看团队任务的完整描述、验收条件与依赖拓扑。
- 前端测试门禁 `test-unit.mjs`、`test-decoupling.mjs` 与 `test-suite.mjs` 均持续 100% 通过。
