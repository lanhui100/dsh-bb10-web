G全屏展开 / 收起快捷消息面板 (Enter填入, A新增, D删除)
W全屏展开 / 收起工作区选择 (面板内 A 新增, D 移除, 切换后自动打开会话列表)
C直进“全工作区进行中”会话列表（所有进行中的会话；用户按 C 打开的再按 C 收起，自动打开后按 C 重进列表；面板内 V 轮换四视图，A 归档选中）
U全屏展开 / 收起多智能体/后台任务看板 (Subagents)
M全屏展开 / 收起模型选择 (按常用与 Provider 分组，F 收藏，D 设默认)
P全屏展开 / 收起运行权限配置
O全屏展开 / 收起当前会话状态面板 (含当前目标)
↑ / ↓ / 回车弹窗内上下选择 / 确认（触控板可用）
N新建空白会话并展开对话框
X一键停止运行中的会话 (仅会话运行中生效)
Q切换运行中追发模式：排队 / 插队 (toast 反馈)
F从该轮分支为新会话（任意已落盘回复均可，J/K 选中优先）
Z一键撤回当前排队中的追发消息并放回输入框
V会话面板内轮换视图：当前工作区 → 全工作区进行中 → 全工作区待处理 → 未分组
A归档当前会话；会话面板内归档 J/K 选中的会话 (归档后自动打开会话列表)
E打开并进入顶部首条通知会话 (Enter)
D关闭顶部首条通知 (Dismiss)
H打开 / 关闭本快捷键速查
